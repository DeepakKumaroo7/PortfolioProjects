# EduLens 360 — AI-Powered Classroom Intelligence System

EduLens 360 is a real-time computer vision system designed to analyze classroom activity, movement, and engagement using detection, tracking, and temporal behavior modeling.

## Features
- Real-time person detection using YOLOv8
- Multi-object tracking with persistent IDs
- Temporal behavior analysis (idle vs moving)
- Privacy-preserving design (no face recognition)
- Modular, extensible architecture

## Tech Stack
- Python, OpenCV
- YOLOv8 (Ultralytics)
- Custom ByteTrack-style tracking
- Temporal heuristics for behavior modeling
